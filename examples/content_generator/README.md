# Content Generator Demo

Multi-agent system tạo content chất lượng cao thông qua workflow: Research → Write → Edit.

## Tính năng

- **Multi-Agent Workflow**: 3 agents chuyên biệt (Researcher, Writer, Editor)
- **Sequential Processing**: Research → Content Creation → Quality Review
- **Content Types**: Blog posts, articles, social media, technical docs
- **Quality Assurance**: Grammar check, SEO optimization, readability analysis
- **Customizable Templates**: Flexible content templates cho different formats

## Architecture

```
Content Brief → Researcher Agent → Writer Agent → Editor Agent → Final Content
                     ↓               ↓              ↓
                 Research Data   Draft Content  Polished Article
```

## Agent Roles

### 1. Researcher Agent
- **Role**: Content Research Specialist
- **Responsibilities**:
  - Gather relevant information and data
  - Identify key points and trends
  - Collect supporting statistics and examples
  - Verify facts and sources

### 2. Writer Agent  
- **Role**: Content Creator
- **Responsibilities**:
  - Create engaging content structure
  - Write compelling copy
  - Maintain consistent tone and style
  - Optimize for target audience

### 3. Editor Agent
- **Role**: Quality Assurance Editor
- **Responsibilities**:
  - Grammar and spelling check
  - Style and tone consistency
  - SEO optimization
  - Readability improvement

## Content Types Supported

### Blog Posts
- Length: 800-1500 words
- Structure: Intro → Body → Conclusion
- Features: SEO optimization, engaging headlines

### Technical Articles
- Length: 1500-3000 words
- Structure: Abstract → Introduction → Methodology → Results → Conclusion
- Features: Code examples, diagrams, references

### Social Media Content
- Length: Platform-specific
- Formats: Posts, threads, captions
- Features: Hashtag optimization, engagement hooks

### Marketing Copy
- Length: Variable
- Types: Landing pages, email campaigns, ads
- Features: Call-to-action optimization, conversion focus

```yaml

    structure: ["hook", "introduction", "main_points", "conclusion", "cta"]

    tone: "conversational"
```

## API Integration

### Programmatic Usage
```python
from content_generator import ContentGenerator

generator = ContentGenerator()

content = await generator.create_content(
    brief="AI trends in fintech",
    content_type="blog_post",
    target_audience="business executives",
    tone="professional",
    length=1200
)

print(content.title)
print(content.body)
print(f"SEO Score: {content.seo_score}")
```

### REST API
```bash
# Start API server
python api_server.py

# Generate content
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "brief": "Machine learning in retail",
    "type": "article",
    "length": 1000
  }'
```

## Troubleshooting

### Common Issues

1. **Low Quality Scores**
   - Check content brief clarity
   - Verify target audience specification
   - Review tone and style settings

2. **SEO Optimization Issues**
   - Ensure keywords are provided
   - Check keyword density settings
   - Verify meta description generation

3. **Generation Timeouts**
   - Reduce content length requirements
   - Simplify content structure
   - Check API rate limits

### Performance Optimization

```yaml
# config.yaml optimizations
performance:
  parallel_research: true
  cache_research_data: true
  batch_processing: true
  
  # Resource limits
  max_concurrent_agents: 3
  research_timeout: 300
  writing_timeout: 600
```
